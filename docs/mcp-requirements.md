# Habit Mentor MCP requirement check

Checked against both root PRDs and the attached MCP engineering specification on 2026-10-14. This matrix covers the MCP integration, not unrelated app-wide PRD features.

| Requirement                                                                                | Implementation                                                                                                   | Verification                                                                                         |
| ------------------------------------------------------------------------------------------ | ---------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------- |
| Reuse backend authority for schedules, streaks, tasks, goals, Today, journal and analytics | MCP calls owner-scoped `/api/v1` GET routes; no direct SQL or duplicated domain engine                           | `test:mcp` compares habit history with the API; existing Today and journal integration tests pass    |
| No separate model-provider inference                                                       | MCP package has SDK/Zod only; mentor prompts guide the connected model                                           | Dependency inspection; `test:mcp` starts without `OPENAI_API_KEY`                                    |
| Local standard MCP transport                                                               | Official SDK `StdioServerTransport`; stdout reserved for protocol                                                | Actual SDK client initializes, discovers and invokes tools; startup-failure test checks empty stdout |
| Account authentication and isolation                                                       | Expiring, hashed, revocable assistant token resolved by API on each allowlisted GET request                      | `test:mcp`: invalid token, second account, blocked account export/write, revocation                  |
| Minimum read-only catalog                                                                  | Ten bounded tools and three prompts; no administrative or arbitrary-request tool                                 | SDK tool/prompt discovery and invocation in `test:mcp`                                               |
| Sensitive journal minimization                                                             | Single-date content tool; mentor context exposes dates/status only                                               | `test:mcp` verifies private content is absent from general context                                   |
| Validation and resource bounds                                                             | Zod inputs, 31-date range, ID/page limits, eight-second API timeout, 256 KiB response/output caps                | Invalid-range and backend-unavailable tests; code review                                             |
| Errors and observability                                                                   | MCP tool errors with request IDs where available; status-only stderr; API logs omit token/content                | Revocation and startup-failure tests; API logger configuration                                       |
| Core app independence                                                                      | Optional Compose profile; API works without MCP process                                                          | Existing Today, journal and mentor tests passed with MCP stopped                                     |
| Local setup and compatibility                                                              | `docs/mcp.md`, `.env.example`, Docker launcher and tested-client matrix                                          | Docker image build and SDK client test                                                               |
| Remote Streamable HTTP/OAuth                                                               | HTTPS `/mcp`, OAuth metadata, dynamic public-client registration, consent, PKCE, refresh rotation and revocation | `test:mcp-remote` with actual SDK HTTP client; hosted-client UI compatibility still unverified       |
| Controlled write tools                                                                     | Not included under current read-only account permission                                                          | Explicit read-only catalog and API write rejection test                                              |

Write tools remain outside the read-only permission. See [ADR 0006](adr/0006-habit-mentor-mcp-boundary.md) and [ADR 0007](adr/0007-remote-mcp-oauth.md).
